# Serene Hands Complete UI Redesign

## Direction
This redesign intentionally moves Serene Hands away from a clinical nurse/doctor aesthetic toward a warm, human, editorial home-care experience.

### Core idea
**Care that feels like home.**

The homepage now leads with emotion and belonging, followed immediately by an Our Story section that explicitly states Serene Hands supports children and adults.

### Adult care positioning
- Older-adult care is visible in the frontend.
- It is presented as **Coming Soon**.
- No older-adult request/booking form has been added.
- Current detailed service pages remain focused on children and young people.

## UI/UX Pro Max workflow applied
- Industry-aware service/landing pattern selection
- Human-first visual style
- Warm editorial palette
- Fraunces + DM Sans typography
- Semantic hierarchy and conversion path
- Responsive design intent for 320–1440+ widths
- Reduced-motion support
- Lucide icons
- Anti-pattern checks against clinical/dashboard styling, excessive cards, fake proof, excessive animation, and generic SaaS aesthetics
- Persisted design system in `design-system/MASTER.md`
- Home page override in `design-system/pages/home.md`
- Project skill in `skills/serene-hands-ui-ux-pro-max/SKILL.md`

## Backend
Backend architecture was intentionally left alone for this phase.
