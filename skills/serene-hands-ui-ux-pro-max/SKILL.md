# Serene Hands UI/UX Pro Max Skill

This project-specific skill adapts the NextLevelBuilder UI/UX Pro Max workflow to Serene Hands. The reference system emphasizes industry-aware design-system generation, style/palette/typography matching, landing-page patterns, UX guidance, accessibility, responsive behavior, motion restraint, and anti-pattern checks.

## Required workflow
1. Understand the user, business objective, primary CTA, and audience.
2. Choose a human-first service/landing pattern instead of a clinical healthcare template.
3. Read `design-system/MASTER.md` before implementing UI.
4. Read page-specific overrides under `design-system/pages/`.
5. Use the existing React/Vite architecture and reusable components.
6. Prefer Lucide SVG icons and semantic HTML.
7. Check 320/375/390/430/768/1024/1280/1440 widths.
8. Audit keyboard focus, contrast, reduced motion, states, and conversion path.
9. Explicitly detect clinical/medical-dashboard styling, excessive cards, excessive rounded surfaces, fake proof, excessive animation, and weak mobile controls.
10. Polish after implementation instead of merely reporting issues.

## Brand rule
Serene Hands should feel like **care, warmth, belonging, and human connection**, not a hospital, clinic, nursing dashboard, or medical marketplace.
